## About Me

직접 만들고, 공격해 보고, 막아 보며 보안을 배우는 정보보호학과 학생 임한글입니다.

정보보안에 관심을 갖게 된 계기는 직접 겪은 보안 사고였습니다. 악성 프로그램 때문에 컴퓨터가 정상적으로 작동하지 않는 일을 겪으며 사이버 공간에서 보안이 얼마나 중요한지 체감했고, 이를 계기로 정보보호학과에 진학했습니다.

대학에서는 리버싱, 디지털 포렌식, 네트워크 보안을 공부하며 하나의 보안 문제를 여러 관점에서 바라보는 법을 익혔습니다. 이후 화이트햇 스쿨 3기와 이스트소프트 KDT 인프라 보안 교육에 참여해 시스템과 네트워크를 직접 구성하고 보안 요소를 적용했습니다. 이 과정에서 개별 기술을 넘어 서비스가 운영되는 환경 전반으로 시야를 넓혔고, 2차 프로젝트에서는 팀장을 맡아 1·2차 프로젝트 모두 우수 프로젝트로 선정되는 결과를 냈습니다.

프로젝트에서 Wazuh, Snort, Zabbix로 서버 로그와 보안 이벤트를 분석하며 데이터 속에서 이상 징후를 찾아내는 일에 흥미를 느꼈습니다. 지금은 이를 AI와 연결하는 데 집중하고 있습니다. 방대한 위협 데이터에서 의미 있는 정보를 식별하고, 서로 다른 정보 간의 연관성을 분석해 결론을 도출하는 기술을 공부하고 있으며, LLM 보안에 대한 내용도 꾸준히 블로그에 정리하고 있습니다.

앞으로 정보보안의 기초와 실무형 프로젝트 경험을 바탕으로 AI 기반 보안 분석 역량을 키워, 실제 사이버 위협을 분석하고 대응하는 데 기여하는 보안 엔지니어가 되겠습니다.
